# Contributing

## Requirements

-   Node.js 18+
-   [PDM](https://github.com/pdm-project/pdm)
-   PowerShell 5.1+
-   [PSScriptAnalyzer](https://github.com/PowerShell/PSScriptAnalyzer)
-   Python 3.8+

Once you have installed all the requirements, run [`/scripts/install-dependencies.sh`](scripts/install-dependencies.sh) to install the development dependencies.

## VSCode configuration

Ubuntu dotfiles have a VSCode workspace that you must use, it configures formatting, linting, testing and other things. To use it open [`.vscode/ubuntu.code-workspace`](.vscode/ubuntu.code-workspace) with VSCode.
