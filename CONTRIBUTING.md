# Contributing

## VSCode configuration

There's a VSCode workspace for the Ubuntu and Windows dotfiles, which you should use to get formatting, linting and a few other things configured.

Both Ubuntu and Windows dotfiles have a VSCode workspace that you must use, these configure formatting, linting, testing, and other things. To use it open [`.vscode/ubuntu.code-workspace`](.vscode/ubuntu.code-workspace) or [`.vscode/windows.code-workspace`](.vscode/windows.code-workspace) with VSCode as appropriate.

## Ubuntu dotfiles requirements

You need to install the development dependencies, to do so you need to install [PDM](https://pdm.fming.dev/latest/#installation) first, then you can install the dependencies by running `pdm install`.
